Privacy Policy

Last updated: 14 August 2026

This policy describes how GD Esports Desktop (“the app”) handles information when you use the Windows client.

What we collect

The app asks you for a Riot ID (game name and tag) and a server hint so it can look up League of Legends data from the Riot Games API. That can include summoner profile, ranked record, match history, timelines, live-game participants, and champion mastery counts.

Optional feedback you submit (title, details, contact) is sent to our Discord webhook so we can fix bugs.

What we do not collect

We do not ask for your Riot password. We do not sell player data. We do not run ads. We do not build a public database of other players beyond what you search inside your own copy of the app.

Where data lives

Linked-account settings and short-lived caches are stored on your PC (local app data). The Windows app does not embed a Riot API key. League data is requested through our HTTPS API proxy (hosted on Render), which holds the Riot key on the server, rate-limits requests, and only forwards calls to official Riot Games API hosts. We do not store your match history in our own database.

Third parties

League data comes from Riot Games. Champion/item images may load from Riot’s Data Dragon / Community Dragon CDNs. Feedback may be delivered via Discord. Those services have their own policies.

Contact

Questions: use Report feedback / bugs in the app, or open an issue on the GitHub repository linked from the download page.
